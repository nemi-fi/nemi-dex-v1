# Glossary

Quick reference for key terms.

## Core Concepts

| Term     | Definition                                                 |
| -------- | ---------------------------------------------------------- |
| **AMM**  | Automated Market Maker — trading via formula (`x × y = k`) |
| **DEX**  | Decentralized Exchange — peer-to-peer trading              |
| **LP**   | Liquidity Provider — deposits tokens to earn fees          |
| **Pool** | Smart contract holding token reserves                      |
| **TVL**  | Total Value Locked — assets in a pool                      |

## Trading

| Term             | Definition                                   |
| ---------------- | -------------------------------------------- |
| **Slippage**     | Price difference between quote and execution |
| **Price Impact** | How your trade affects the pool price        |
| **Gas**          | Transaction fee paid in ETH                  |

## Privacy

| Term         | Definition                          |
| ------------ | ----------------------------------- |
| **ZK Proof** | Proves truth without revealing data |
| **Aztec**    | L2 with private smart contracts     |
| **PXE**      | Private eXecution Environment       |

## Risk

| Term    | Definition                                          |
| ------- | --------------------------------------------------- |
| **IL**  | Impermanent Loss — LP value loss from price changes |
| **MEV** | Maximal Extractable Value — Nemi prevents this      |
