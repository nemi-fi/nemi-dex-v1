# Risks

:::caution Read First
Understand these risks before trading or providing liquidity.
:::

## Smart Contract

- Bugs can cause **permanent fund loss**
- Contracts are **immutable** (can't be fixed)
- Built on audited Aztec, but risk remains

**Action:** Start small. Only risk what you can lose.

## Financial

| Risk                 | Description                   | Mitigation               |
| -------------------- | ----------------------------- | ------------------------ |
| **Impermanent Loss** | Price changes reduce LP value | Use stable pairs         |
| **Slippage**         | Price moves during tx         | Set 0.5-1% tolerance     |
| **Low Liquidity**    | Bad execution price           | Check TVL before trading |

## Privacy

| Private      | Public        |
| ------------ | ------------- |
| Your address | Pool reserves |
| Amounts      | Prices        |
| History      | Volume        |

:::warning
Privacy protects trading activity, not full anonymity. Funding sources and timing can still identify you.
:::

## Security Checklist

- [ ] Never share seed phrase
- [ ] Verify URL is **nemi.fi**
- [ ] Use hardware wallet for large amounts
- [ ] Double-check addresses before confirming

## Market

- **Volatility** — Token prices can crash
- **Rug pulls** — Stick to established tokens
- **Regulatory** — Laws are evolving

## Emergency

| Situation               | Action               |
| ----------------------- | -------------------- |
| Exploit suspected       | Withdraw immediately |
| Seed phrase lost        | Funds gone forever   |
| Seed phrase compromised | Transfer funds NOW   |
